## Як запустити

Потрібен встановлений [.NET SDK 10](https://dotnet.microsoft.com/download). Відкрий термінал у папці `lab04` і виконай:

```
dotnet run lab4.cs
```

## Що робить програма

1. `linearSearch` проходить масив з початку, повертає індекс знайденого значення або −1.
2. `binarySearch` працює звичайним циклом на відсортованому масиві, повертає індекс або −1.
3. Обидві функції збільшують лічильник `comparisons` на кожному порівнянні елемента зі шуканим значенням.
4. Програма запускає обидва пошуки на восьми випадках (перший, останній, посередині, три відсутніх, масив з одного елемента, порожній масив).
5. Окремо виконується експеримент: бінарний пошук на невідсортованому масиві `data`.
